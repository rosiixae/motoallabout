# MotoAllAbout

Motorrad-Pflege-App für (neue) Motorradfahrer*innen: Erinnerungen an Wartung (Kette, Ölwechsel, Service, Reifendruck …), Kalender, Tipps & Tricks und «Mein Motorrad» mit Pixel-Motorrad.

## Ordner

| Ordner / Datei | Inhalt |
|---|---|
| `mobile/` | Die App (Expo / React Native), siehe `ROADMAP.md` |
| `supabase/migrations/` | Datenbank-Migrationen. Neue Dateien auf `main` spielt Supabase automatisch ein. |
| `supabase/config.toml` | Supabase-Konfiguration |
| `datenbank/` | Infos zur Datenbank (README) und `make_seed.py`, das die Startdaten aus den CSVs erzeugt |
| `motorrad-liste-schweiz.csv` | Modellkatalog Schweiz mit Wartungsintervallen und Zulassungszahlen |
| `warnleuchten.csv` | Warnleuchten mit Bedeutung und «Was tun» |
| `pixel-motorrad-briefing.md` | Briefing für die animierten Pixel-Motorräder |
| `projekt-dateien/` | Skizze und Bilder |

Plan und Stand: [ROADMAP.md](ROADMAP.md)
